## Brand & Style

The brand personality is institutional yet progressive: calm, deeply trustworthy, rigorous, and technologically advanced. It is tailored for Tamil Nadu State Board Class 12 educators, evaluators, educational administrators, and students spanning both Academic and Vocational streams in English and Tamil mediums. 

The emotional response should evoke pedagogical certainty, analytical precision, and frictionless focus. The visual direction balances modern high-craft SaaS architecture with academic dignity. It avoids juvenile gamification and sterile bureaucracy in favor of crisp typography, measured data densities, layered architectural white space, subtle multi-tier atmospheric shadows, and deliberate micro-gradients for key metric indicators. Bilingual clarity (Tamil and English) is fundamental; scripts must coexist with optical balance and equivalent typographic hierarchy.

## Colors

The palette establishes an authoritative, high-contrast foundational canvas supported by precise semantic anchors:

- **Primary (`#4F46E5` / Indigo-600):** Represents cognitive computing, primary actions, active navigational states, and AI generation touchpoints.
- **Secondary (`#14B8A6` / Teal-500):** Anchors verification, secondary analytical visualizers, subject taxonomy nodes, and validated states.
- **Tertiary / Accent (`#F59E0B` / Amber-500):** Flags alerts, mid-tier confidence levels, pending actions, and curricular milestones.
- **Canvas & Neutral Surfaces:**
  - App Canvas: `#F8FAFC` (Slate-50) for reduced eye strain during sustained evaluation sessions.
  - Surface Containers: `#FFFFFF` (Pure White) for distinct elevation layers.
  - Structural Borders: `#E2E8F0` (Slate-200) for clean delineations.
  - Text Primary: `#0F172A` (Slate-900) ensuring WCAG AAA accessibility.
  - Text Muted: `#64748B` (Slate-500) for metadata, labels, and citations.
- **Semantic Accents:**
  - Emerald (`#10B981`): Approved states, verified curriculum benchmarks, high confidence (>90%).
  - Rose (`#EF4444`): Critical alerts, locked test papers, low confidence (<70%), strict validation errors.
  - Sky (`#0284C7`): Informational notices, blueprinted question bank links.

## Typography

Typographic scale is structured around `Inter` for Latin numerals, metadata, structural interfaces, and English prose, backed by `Noto Sans Tamil` across matching weights for Tamil text.

### Script Balancing & Tamil Typesetting Rules
- **Line Heights:** When Tamil text is rendered, line-height tokens must expand by a factor of 1.15x relative to English defaults to prevent clipping of vowel sign modifiers (kombu, pulli, and virama markers).
- **Weight Pairing:** Tamil letterforms render with greater visual density. Pair `Inter 600` with `Noto Sans Tamil 500` or `Inter 500` with `Noto Sans Tamil 400` within mixed UI strings to preserve identical optical balance.
- **Formulas & Question Codes:** Question identifiers, curriculum numbering codes (e.g., `TN-MAT-C12-04`), and assessment statistics use monospaced figures to maintain tabular alignment.

## Layout & Spacing

The interface employs a desktop-first responsive 12-column fluid grid system bounded by a max container width of 1440px to preserve data density on large evaluation displays.

### Layout System
- **Desktop (>=1280px):** 12-column grid, 1.5rem gutters, 2rem canvas margins. Navigation lives within a persistent, collapsible 280px left rail with dual-stage contextual side panels for grading rubrics and citation inspectors.
- **Tablet (768px - 1279px):** 8-column grid, 1rem gutters, 1.5rem margins. Primary navigation collapses to an off-canvas drawer or top toolbar; side-by-side verification panels switch to a split-screen or stacked modal layout.
- **Mobile (<768px):** 4-column grid, 1rem gutters, 1rem canvas margins. Complex question tables reflow into discrete vertical evaluation cards.

### Spacing Hierarchy
- Spacing operates on a rigid 4px/8px incremental base. Internal card padding strictly observes `space-lg` (24px) for content surfaces and `space-md` (16px) for compact status blocks and metadata citation groups.

## Elevation & Depth

Visual hierarchy combines low-contrast borders with soft, ambient, multi-tier atmospheric shadows. Avoid hard drop shadows or opaque black elevations.

- **Level 0 (Flat / Canvas):** Applied to the base canvas (`#F8FAFC`). No shadow. Borderless or defined via structural 1px dividers in `#E2E8F0`.
- **Level 1 (Card & Modular Panels):** Applied to resting content containers, question cards, and tabular surfaces. 
  - `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04);`
  - Border: 1px solid `#E2E8F0`.
- **Level 2 (Hover / Active State Cards / KPI Panels):** Applied to interactive cards on hover, active question editors, and subtle metric cards.
  - `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.05), 0 4px 6px -4px rgba(15, 23, 42, 0.03);`
  - Border: 1px solid `#CBD5E1`.
- **Level 3 (Flyouts, Menus & Citation Panels):** Applied to dropdowns, rubric citation popovers, and sticky inspection drawers.
  - `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04);`
  - Border: 1px solid `#CBD5E1`.
- **Level 4 (Modals & Confirmation Sheets):** Applied to dialogs for paper publication or batch generation.
  - `box-shadow: 0 25px 50px -12px rgba(15, 23, 42, 0.18);`
  - Backdrop: `rgba(15, 23, 42, 0.4)` with 4px backdrop blur.

## Shapes

The interface implements a refined, rounded visual hierarchy:

- **Base Components (`roundedness: 2` - 0.5rem / 8px):** Form controls, inputs, standard buttons, source citation nodes, data table cells, and code wrappers.
- **Card Containers (`rounded-2xl` - 1rem / 16px):** Primary UI cards, metric KPI modules, rubric breakdown cards, and question comparison blocks.
- **Pill Badges (`rounded-full` - 9999px):** Status chips, confidence badges, bilingual language toggles, exam year indicators, and academic/vocational stream tags.

## Components

### 1. Cards & KPI Modules
- **Default Card:** Surface `#FFFFFF`, 1px border `#E2E8F0`, Level 1 elevation, `1rem` corner radius, `space-lg` internal padding.
- **KPI Gradient Cards:** Background features an ultra-subtle directional gradient (e.g., Indigo-50 to White at 135deg). Accompanied by a 24px line icon inside a soft 10% tinted primary container, followed by a bold metric label and percentage delta tag.

### 2. Buttons & AI Action Controls
- **Primary AI Action (Approve):** Background `#10B981` (Emerald), text `#FFFFFF`, hover `#059669`. Used to confirm model-generated questions and marking keys.
- **Secondary AI Action (Edit):** Surface `#FFFFFF`, 1px border `#CBD5E1`, text `#334155` (Slate-700), hover `#F8FAFC`.
- **Tertiary AI Action (Dismiss / Ghost):** Transparent background, text `#64748B`, hover background `#F1F5F9` (Slate-100).
- **Generate / Intelligence Action:** Background `#4F46E5` with an integrated line-art sparkle icon.

### 3. Status Chips & Pill Badges
Height: 24px, font: `label-sm`, padding: `0.125rem 0.625rem`, shape: `rounded-full`.
- **Draft:** Background `#F1F5F9` (Slate-100), text `#475569` (Slate-600), border `#E2E8F0`.
- **AI-Suggested:** Background `#EEF2FF` (Indigo-50), text `#4F46E5` (Indigo-600), border `#C7D2FE`, with a leading 12px spark icon.
- **Verified:** Background `#F0FDFA` (Teal-50), text `#0D9488` (Teal-600), border `#99F6E4`.
- **Approved:** Background `#ECFDF5` (Emerald-50), text `#059669` (Emerald-600), border `#A7F3D0`.
- **Locked:** Background `#FEF2F2` (Rose-50), text `#DC2626` (Rose-600), border `#FECACA`, leading lock icon.

### 4. Confidence Meters
Horizontal metric badges with micro-progress rings or bars:
- **High (>90%):** `#10B981` indicator bar, `#ECFDF5` track, bold numeric text.
- **Medium (70% - 89%):** `#F59E0B` indicator bar, `#FFFBEB` track.
- **Low (<70%):** `#EF4444` indicator bar, `#FEF2F2` track, alongside a review prompt icon.

### 5. Source Citation Chips
Compact structural tags (`0.375rem` radius or pill) linking questions directly to curriculum sources:
- **Style:** Surface `#F8FAFC`, border `#E2E8F0`, text `#475569`, left-bordered or icon-tagged by type:
  - *Document / Textbook:* Book icon + "Vol 1, Ch. 3".
  - *Book-Back:* Bookmark icon + "Book-back Q14".
  - *Exam History:* Clock icon + "March 2023 Public Exam".

### 6. Bilingual Language Toggle
Segmented control pill with sliding background indicator:
- Active state: `#FFFFFF` elevation pill, text `#0F172A`, font weight 600.
- Inactive state: Transparent, text `#64748B`.
- Options: `தமிழ்` (Noto Sans Tamil) / `English` (Inter).

### 7. Form Controls & Stepper Wizards
- **Inputs & Dropdowns:** 40px height, border 1px `#CBD5E1`, background `#FFFFFF`, text `#0F172A`. Focused: 2px ring `#4F46E5` with `#EEF2FF` halo.
- **Steppers:** Linear path showing blueprint generation milestones (e.g., Curriculum Mapping -> Difficulty Weighting -> AI Generation -> Human Verification). Completed steps show Emerald checkmarks; active steps display an Indigo ring with an inner dot.
