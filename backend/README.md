# ExamIQ — FastAPI Backend

High-performance Python FastAPI backend for the **JM Vertex ExamIQ** Examination & Learning Intelligence System.

Conforms 100% to the frontend contracts specified in `static/js/api/endpoints.js` and `templates/views/api_explorer.html`.

---

## Architecture Overview

```
ExamIQ/
├── app.py                      # Frontend Web Server (Flask serving HTML/CSS/JS shell)
├── templates/                  # Frontend HTML Templates (Untouched)
├── static/                     # Frontend Static CSS/JS Assets (Untouched)
├── run_backend.py              # Convenient runner for the FastAPI backend
├── requirements-backend.txt    # Python dependencies for the backend
├── .env                        # Environment configuration (API_BASE_URL, FRONTEND_PORT, etc.)
└── backend/
    ├── __init__.py
    ├── main.py                 # FastAPI application, CORS middleware, router registration
    ├── config.py               # Environment configuration and settings
    ├── database.py             # In-memory persistent data store with TN HSC Class 12 domain data
    ├── models.py               # Pydantic schemas for request validation and response typing
    └── routers/
        ├── auth.py             # /auth/login, /auth/emis-sso
        ├── syllabus.py         # /syllabus/{classId}/{subjectId}, /syllabus/lock/toggle, /syllabus/subtopic/status
        ├── resources.py        # /resources, /resources/import, /resources/version-diff
        ├── questions.py        # /questions (GET search, POST add)
        ├── papers.py           # /papers/generate, /papers/regenerate-question
        ├── evaluations.py      # /evaluations/upload-scan, /evaluations/{id}/approve, /evaluations
        ├── marks.py            # /marks/{classId}/{testId}, /marks/batch-import
        ├── students.py         # /students/{studentId}/learning-dna, /students
        ├── remedial.py         # /remedial/generate-drill

        └── admin.py            # /admin/audit-logs, /admin/schools
```

## Key Features

1. **Rule 1 Enforced (Curriculum Progress Lock)**:
   - When active, `/papers/generate` dynamically inspects syllabus completion status and strictly filters out untaught units (e.g., Conics, Vectors, Differential Calculus).
   - Can be toggled live via `PUT /api/v1/syllabus/lock/toggle`.
2. **CORS Fully Enabled**:
   - Supports cross-origin requests from the frontend running on `http://localhost:3000` or any local origin.
3. **Dual Routing (Prefix Tolerance)**:
   - All routes are mounted both with `/api/v1` prefix (`/api/v1/auth/login`) and directly at root (`/auth/login`), preventing any path-mismatch errors.
4. **Dynamic Path Parameter Tolerance**:
   - Routes gracefully handle test sample IDs (such as `sample-id` generated by the frontend API Explorer) and real student/class/trade IDs alike.
5. **Interactive Swagger & ReDoc Documentation**:
   - Complete OpenAPI 3.0 specification available at `/openapi.json`.
   - Swagger UI at `/docs`.
   - ReDoc UI at `/redoc`.

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements-backend.txt
```

### 2. Start the Backend Server
```bash
python run_backend.py
```
Or directly with uvicorn:
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

The backend will start at `http://localhost:8000`.

### 3. Start the Frontend Web Server (in a separate terminal)
```bash
python app.py
```
The frontend will start at `http://localhost:3000`.

### 4. Switch Frontend to Live Mode
1. Open `http://localhost:3000` in your browser.
2. Sign in with:
   - **Email**: `admin@gmail.com`
   - **Password**: `admin@123`
3. Navigate to **API Explorer** from the sidebar (`System & Settings` -> `API Explorer`).
4. In the top hero card, toggle mode from **Mock Data** to **Live API**.
5. Select any endpoint and click **Test Endpoint (LIVE MODE)** to test real-time communication with the FastAPI backend.

## Endpoint Contract Summary

| Category | Method | Path | Summary |
|---|---|---|---|
| Auth | POST | `/api/v1/auth/login` | Teacher / Staff / Admin login with EMIS credentials |
| Auth | POST | `/api/v1/auth/emis-sso` | TN EMIS State Portal SSO Callback |
| Syllabus | GET | `/api/v1/syllabus/{classId}/{subjectId}` | Retrieve Structured Syllabus Hierarchy & Lock Status |
| Syllabus | PUT | `/api/v1/syllabus/lock/toggle` | Toggle Teaching Progress Lock (Rule 1) |
| Syllabus | POST | `/api/v1/syllabus/subtopic/status` | Update Topic / Subtopic Teaching Status |
| Resources | GET | `/api/v1/resources` | List SCERT Textbooks, Public Exam Archives & Guides |
| Resources | POST | `/api/v1/resources/import` | Upload & Ingest New Textbook / Paper for OCR |
| Resources | GET | `/api/v1/resources/version-diff` | Get Syllabus Differential Audit Comparison |
| Question Bank | GET | `/api/v1/questions` | Search and Filter Question Repository |
| Question Bank | POST | `/api/v1/questions` | Add / Author New Question with Stepwise Rubric |
| Paper Generator | POST | `/api/v1/papers/generate` | Generate Complete Question Paper via AI Blueprint Engine |
| Paper Generator | POST | `/api/v1/papers/regenerate-question` | Swap / Regenerate Individual Question in Paper |
| Evaluations | POST | `/api/v1/evaluations/upload-scan` | Upload Scanned Answer Sheet for AI OCR & Scoring |
| Evaluations | PUT | `/api/v1/evaluations/{evaluationId}/approve` | Teacher Approves or Adjusts AI Evaluation Marks |
| Marks | GET | `/api/v1/marks/{classId}/{testId}` | Get Class Marks Grid with Discrepancy Flags |
| Marks | POST | `/api/v1/marks/batch-import` | Import Marks from CSV or Excel Spreadsheet |
| Student DNA | GET | `/api/v1/students/{studentId}/learning-dna` | Get Granular Student Learning DNA Profile |
| Remedial | POST | `/api/v1/remedial/generate-drill` | Generate AI Personalized Remedial Worksheet |
| Homework | POST | `/api/v1/homework/create` | Create Differentiated or Class-Wide Homework Assignment |
| Vocational | GET | `/api/v1/vocational/{tradeCode}` | Get Vocational Trade Modules & Workshop Rubrics |
| Reports | GET | `/api/v1/reports/class-summary/{classId}` | Generate Class Curricular Progress & Mark Reports |
| Admin | GET | `/api/v1/admin/audit-logs` | Retrieve System Audit Trails |
| Admin | GET | `/api/v1/admin/schools` | List Connected School Tenants |
